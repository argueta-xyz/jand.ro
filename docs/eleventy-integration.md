# Eleventy (11ty) integration

How `src/` is wired: Markdown content, Nunjucks layouts, Tailwind CSS from a PostCSS build, and global data.

## Project structure

```text
.
├── src
│   ├── albums/          # Album entries (photo grid + lightbox)
│   ├── assets/
│   │   ├── css/         # input.css → app.css (PostCSS + Tailwind)
│   │   └── fonts/       # .woff2 from npm run fonts:copy (often gitignored)
│   ├── posts/           # Markdown articles
│   ├── _data/           # site.json, uiClasses.js (shared class strings)
│   └── _includes/
│       ├── layouts/     # base, home, post, post-list, album
│       ├── macros/      # ui.njk (sidebar / TOC helpers)
│       └── components/  # top-nav, footer, lightbox, cards, etc.
├── theme/
│   └── colors.cjs       # Tailwind palette (see theme/README.md)
├── eleventy.config.js
├── tailwind.config.js
└── package.json
```

[`src/_data/uiClasses.js`](../src/_data/uiClasses.js) groups Tailwind class strings: shared (`layout`, `sidebar`, `breadcrumb`, `grid`, `prose`, `topNav`, `footer`) and contextual (`post`, `postList`, `album`, `home`, `featured`, `previewCard`). In templates use dotted paths, e.g. `uiClasses.sidebar.card`, `uiClasses.post.byline.row`.

## Articles (`src/posts/`)

Example front matter:

```markdown
---
layout: layouts/post.njk
title: "Article title"
date: 2025-01-15
author: "Author Full Name"
tags:
  - Tag One
  - Tag Two
readingTime: "8 min read"
heroImage: "/assets/images/hero-example.jpg"
excerpt: "Short summary for cards and meta."
---
Opening paragraph (no `#` title here; the layout renders the `<h1>`).

## First section

Use `##` / `###` for in-article headings. They get stable `id` attributes (via `markdown-it-anchor`, level 2+) and feed the post sidebar TOC. Sidebar labels come from `site.ui.sidebar.post` in [`site.json`](../src/_data/site.json).

## Second section

More body text.
```

Optional: `summary`, `authorAvatar` (byline image URL). Default avatar: `site.defaults.authorAvatar` in `site.json`.

**Tags:** Each `tags` entry appears in breadcrumbs (links to `/posts/tags/<slug>/`) and in the tag sidebar on list pages. Tag URLs are generated by [`src/posts/tag-list.md`](../src/posts/tag-list.md) (pagination over `collections.postTagIndex`).

## Albums (`src/albums/`)

Use `layout: layouts/album.njk`. The `albums` collection includes only files with that layout. The `/albums/` index uses `layouts/post-list.njk` with `listSection: albums` in its front matter. Tag filter pages use [`src/albums/tag-list.md`](../src/albums/tag-list.md) and `collections.albumTagIndex`. Add a `tags` array in album front matter the same way as for posts.

**Front matter example:**

```yaml
---
layout: layouts/album.njk
title: Sample album
date: 2025-02-01
permalink: /albums/sample-album/
tags:
  - Topic A
  - Topic B
photos:
  - url: /assets/images/photo-01.jpg
    alt: Image description
    caption: Optional caption (lightbox panel)
    location: Optional place name
    exif:
      Camera: Camera model
      Lens: Lens description
      Aperture: f/5.6
      Shutter: 1/500s
      ISO: "200"
---
Optional markdown intro below the title.
```

- **`url`** — Required for the grid thumbnail and lightbox.
- **`caption`**, **`location`**, **`exif`** — Optional. If a slide has no usable metadata, the lightbox can hide the side panel for that image. EXIF is hand-authored YAML (no extraction from files).

[`layouts/album.njk`](../src/_includes/layouts/album.njk) builds the grid; cells use `data-lightbox` / series JSON via the [`lightboxPayload` / `lightboxSeriesJson` filters](../eleventy.config.js).

## Site copy and brand

Edit [`src/_data/site.json`](../src/_data/site.json) for name, hero copy, nav (`ui.nav.primary`, `ui.nav.external`, `ui.nav.actions` with icon keys from `macros/icon.njk`), footer, aria strings, sidebar copy (`ui.sidebar.*`), lightbox labels (`ui.lightbox.*`), etc. Templates use `site.brand.*`, `site.ui.*`, and `site.defaults.*`.

## Template roles

- **`layouts/base.njk`** — HTML shell, viewport, title, single stylesheet link to `/assets/css/app.css` (built from `src/assets/css/input.css`).
- **`layouts/home.njk`** — Hero (`site.hero_title`, `site.description`), scroll hint, featured first post, then a card grid for remaining posts. No lightbox.
- **`layouts/post.njk`** — Article: TOC from `##`+ headings, tag breadcrumbs, related posts.
- **`layouts/post-list.njk`** — Browse grid + tag sidebar for `/posts/` and `/posts/tags/<slug>/` (default `listSection: posts`), or `/albums/` and `/albums/tags/<slug>/` when `listSection: albums` is set (see album `index.md` and `tag-list.md`).
- **`layouts/album.njk`** — Album title, optional body, photo grid, [`components/lightbox.njk`](../src/_includes/components/lightbox.njk).
- **`components/lightbox.njk`** — Full-screen viewer; optional caption, location, EXIF. Close: button, backdrop click, Escape.

## Article previews (home)

- [`article-preview-featured.njk`](../src/_includes/components/article-preview-featured.njk) — First post in the collection.
- [`preview-card.njk`](../src/_includes/components/preview-card.njk) — Shared card for posts and albums; set `item` to the collection entry before `{% include %}`.

## Assets and styles

- **CSS:** `npm run css:build` runs `fonts:copy` then PostCSS: `src/assets/css/input.css` → `src/assets/css/app.css`. `npm run dev` also builds CSS once, then `css:watch` keeps `app.css` updated. Eleventy passthrough copies `src/assets` to `_site/assets`.
- **Tailwind:** [`tailwind.config.js`](../tailwind.config.js) extends theme colors from [`theme/colors.cjs`](../theme/colors.cjs) (optional env: `THEME_SEED`, `THEME_TERTIARY_SEED`).
- **Fonts:** Self-hosted variable fonts via `@fontsource-variable/*` and [`scripts/copy-fonts.js`](../scripts/copy-fonts.js).

## Configuration

[`eleventy.config.js`](../eleventy.config.js) sets `dir.input` to `src`, copies `src/assets` to `_site/assets`, configures Markdown with `markdown-it` + `markdown-it-anchor` (anchors from `##` upward), registers collections **`posts`**, **`postTagIndex`**, **`albums`**, **`albumTagIndex`**, and filters: `postDate`, `takeRelated`, `lightboxPayload`, `lightboxSeriesJson`, `albumCoverUrl`, `tagSlug`, `postsWithTagSlug`, `albumsWithTagSlug`, `navIsActive`, `navActivePrimaryLabel`.

In Nunjucks, use `collections.posts | length` (not `.length`) where the filter form is required.
